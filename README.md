# 数学互动课堂

四年级第三至第九单元的统一课程网站。无需服务器端程序或在线配音服务，课程所用视频、旁白和图片均随网站提供。

## 收录内容

- 第三单元：总价、单价与数量；路程、速度与时间；不同用时的组合路程；原相遇讲解、六种相遇探索及综合应用。
- 第四单元：加法运算律、乘法交换律和结合律、乘法分配律，3课。
- 第五单元：三角形的认识与分类、三边关系与内角和、平行四边形与梯形，3课。
- 第六单元：小数的意义与读写、性质与大小比较、小数点移动、单位换算、近似数与改写，5课。
- 第七单元：小数加减笔算、混合运算与简便计算，2课。
- 第八单元：轴对称、平移与旋转，2课。
- 第九单元：平均数、分段整理数据，2课。

七个单元的教学主干已接入；不表示教材全部练习已经逐题视频化，也不表示已经验证儿童学习效果。第三单元是完整的互动学习路线，第四至第九单元共17个动画开场互动视频课。

## 使用

打开首页 `index.html`，按单元进入。课程页上方可返回本单元或全部单元。第三单元的原讲解和六种情况保留在同一条学习路线中。

第三单元的思考和草稿仅保留在当前页面内，刷新、关闭或离开该页面会清空。第四至第九单元沿用原播放器的本机浏览器保存方式，可以在课程内重置。不上传学生作答，不提供跨设备账号同步；共享设备使用后可重置课程记录。

## GitHub Pages 发布

建议将本文件夹中的内容放在单独的仓库根目录，而非上传外层知识库。仓库默认分支使用 `main`。

1. 上传本文件夹的全部内容，保留 `assets/`、`units/` 等目录结构。
2. 打开仓库 Settings → Pages，将 Source 设为 GitHub Actions。
3. 在 Actions 中运行 Publish mathematics classroom，或向 main 推送更新。
4. 部署成功后，Pages 设置中会显示网站地址。

若网页上传不便，也可用 GitHub Desktop 将本文件夹作为独立仓库发布。视频已经从课程HTML中无损分离，不需将ZIP文件上传到网站。所有运行链接使用相对路径，可放在项目型Pages子路径下。

GitHub 官方文档：[Pages部署](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)、[网站容量限制](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)。

本发布包收录现有课件的学生使用版本，未包含学生画像、诊断档案、作答数据、原始教材文件和制作过程记录。原视频字节与原交互脚本保留；新增统一导航。
